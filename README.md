# Marketing Analytics Data Pipeline

This project analyzes marketing campaign data to identify customer behavior, campaign response, and purchasing patterns using Python and machine learning techniques.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Google Colab

## Project Workflow
1. Data Cleaning
2. Feature Engineering
3. Exploratory Data Analysis (EDA)
4. Customer Segmentation
5. Machine Learning Model
6. Business Insights

## Key Features
- Cleaned and processed marketing campaign dataset
- Created new features such as total spending and purchase behavior
- Visualized campaign responses and customer patterns
- Applied clustering and machine learning to understand customer segments

## Business Insights
- High spending customers can be targeted for premium campaigns
- Purchase behavior differs across channels
- Customer segmentation helps improve marketing targeting strategies
